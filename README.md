# そぞろつづり

**そぞろつづり ― 小さな旅の記録帳**

気の向くままに歩いた旅を、そっと綴っておく帳面。
旅行ごとの日程・写真付きの記録・費用・持ち物・メモを、スマホ1台で残すための個人用アプリです。

- アプリ：https://tokageto.github.io/sozorotsuzuri/ （スマホのChromeで開き、ホーム画面に追加）
- 使い始めの手順：[docs/setup.md](docs/setup.md)

## できること（v0.2.1 見本）

| 機能 | 内容 |
|---|---|
| 旅行の管理 | 旅行中／これから／これまで に分けて表示。旅行中の旅は開いたときに自動で表示 |
| 日程 | 日別のタイムライン。場所は地図で開け、「行き方」でGoogleマップの経路検索（公共交通）を開く |
| 記録 | 写真（自動で縮小）・ひとこと・現在地・スポットを1件として残す。市町村はサーバーとの同期時に自動で付く |
| 費用 | 交通費とそれ以外を分けて集計。カテゴリ別・市町村別の内訳。交通費は出発地・到着地も残せる |
| 持ち物 | 定番リストからの追加とチェック |
| メモ | 予約番号・住所など |
| ハイライト画像 | 旅の写真4枚と集計を1枚の画像（1080×1350）にまとめ、共有・保存できる。日付や費用など、入れる項目を選べる |
| 電波がないとき | すべて端末に保存して動く。電波が戻ると自動で同期（写真も） |
| バックアップ | 文字データをJSONファイルに書き出し・読み込み |

## 構成

| フォルダ | 内容 |
|---|---|
| `web/` | スマホ用の画面（PWA）。GitHub Pages で公開（`.github/workflows/pages.yml`） |
| `gas/` | Google Apps Script。データと写真の保存、同期、市町村の自動付与 |
| `docs/` | 要件定義書・使い始めの手順・交通事業者データ台帳 |
| `tests/` | GASの同期APIのテスト（ブラウザで開く） |
| `tools/` | アイコン作成スクリプト |

## 開発メモ

- 画面の確認：リポジトリの一番上で `python -m http.server 8765 --directory web` → http://localhost:8765/
- GASのテスト：リポジトリの一番上で `python -m http.server 8765` → http://localhost:8765/tests/gas-test.html
- ビルドは不要（素のHTML/CSS/JavaScript）
