# そぞろつづり

**そぞろつづり ― 小さな旅の記録帳**

気の向くままに歩いた旅を、そっと綴っておく帳面。
旅行ごとの日程・持ち物・費用・写真付きの記録を、スマホ1台で残すための個人用アプリです。

## 構成

| フォルダ | 内容 |
|---|---|
| `gas/` | Google Apps Script（データの保存・API）。現在は v0.1 の試作（GASの画面付き） |
| `docs/` | 要件定義書など |
| `web/` | スマホ用の画面（PWA）。v0.2 で追加予定。GitHub Pages で公開 |

## 状態

- v0.1：GASだけで動く試作（旅行管理・日程・持ち物・費用・メモ）。動作は未確認
- v0.2：PWA＋GAS の構成に移行予定

詳しくは [docs/requirements.md](docs/requirements.md) を参照してください。
