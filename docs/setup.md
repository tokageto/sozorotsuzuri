# そぞろつづり 使い始めの手順

## 1. スマホで開く（サーバーなしでも使えます）

1. スマホのChromeで **https://tokageto.github.io/sozorotsuzuri/** を開く
2. メニュー（︙）→「ホーム画面に追加」（または「アプリをインストール」）
3. ホーム画面の「そぞろつづり」から開く

この時点で、データはスマホの中だけに保存されます。電波がなくても使えます。
まず試すときは、一覧画面の「見本の旅を入れてみる」を押してください。

> ホーム画面に追加して使うと、端末のデータが消されにくくなります（特にiPhone）。

## 2. サーバー（GAS）を用意する（任意・おすすめ）

サーバーを用意すると、記録や写真がGoogleドライブに保存され、スマホとPCで同じデータを使えます。機種変更やスマホの故障にも備えられます。

### 2-1. スクリプトを作る

1. PCで https://script.google.com を開き、「新しいプロジェクト」を作る
2. プロジェクト名を「そぞろつづり」にする
3. 左の「コード.gs」の中身をすべて消し、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) の中身を貼り付けて保存
4. 左の「プロジェクトの設定」（歯車）→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
5. エディタに戻り「appsscript.json」を開いて、[`gas/appsscript.json`](../gas/appsscript.json) の中身に置き換えて保存

### 2-2. 初期設定（setup）を実行する

1. エディタ上部の関数の選択で **setup** を選び、「実行」
2. 「承認が必要です」と出たら、自分のGoogleアカウントを選んで許可する
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「そぞろつづり（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので問題ありません
3. 下の「実行ログ」に次の3行が出ます
   - データ：スプレッドシートのURL
   - 写真フォルダ：ドライブのフォルダのURL
   - **合言葉**：アプリに入力する長い文字列（他の人に見せない）

### 2-3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車）→「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 説明：そぞろつづり
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にしても、合言葉を知らない人はデータを読み書きできません（要件定義 5.2）。

### 2-4. アプリにつなぐ

1. アプリの右上の ⚙️（設定）を開く
2. 「GASのURL」にウェブアプリのURL、「合言葉」に 2-2 の合言葉を入れる
3. 「保存して接続テスト」を押す → 「接続できました」と出れば完了

以後は、アプリを開いたとき・保存したとき・電波が戻ったときに自動で同期します。

## 3. GASのコードを更新したとき

1. Code.gs を貼り替えて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン」を「新バージョン」→「デプロイ」

URLは変わらないので、アプリ側の設定はそのままで大丈夫です。

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| 「合言葉が違います」 | 設定の合言葉を確認。GASの実行ログで setup をもう一度実行すると、今の合言葉が表示されます |
| 「サーバーの初期設定（setup）がまだです」 | 2-2 を行う |
| 合言葉が漏れたかもしれない | GASで resetApiKey を実行し、新しい合言葉をアプリに入れ直す |
| 同期エラーが続く | 設定画面の「状態」の文言を確認。デプロイの「アクセスできるユーザー」が「全員」になっているか確認 |
| 他の端末で撮った写真が出ない | 写真の「タップで読み込む」を押すと、サーバーから取り込みます |
