# 交通事業者データ台帳

交通事業者ごとに、「どのデータが、どんな条件で使えるか」と連絡先を記録する台帳です。
規約は変わることがあるため、**確認日**を必ず記録し、取得する前に見直します（目安：半年に1回、または取得のしくみを変えるとき）。

> 2026-11-27 の調査は、AIがWebページを読み取って行いました。ページの文章を要約して読む方式のため、規約の引用は原文どおりでない場合があります。「未確認」と書いた項目や、実際に取得を始める前には、公式ページを自分の目で確認してください。

## 判定の決まり

| 判定 | 意味 | アプリでの扱い |
|---|---|---|
| ◎ 公開データ | GTFS・ODPTなどで、ライセンス付きで公開されている | 本人も他の利用者も使える（出典などを表示） |
| ○ 取得可 | robots.txt と利用規約の両方で、自動取得が禁止されていない | 月1回程度まで取得してよい。他の利用者への表示は、規約で再配布が許されている場合のみ |
| △ 要問い合わせ | 規約があいまい、または禁止されているが、事業者に問い合わせる価値がある | 了解をもらえるまで取得しない |
| × 不可 | 自動取得が禁止されている | 取得しない。外部アプリとの連携やマイ時刻表で対応する |
| ？ 未確認 | まだ調べていない、または読み取れなかった | 取得しない |

## 確認の手順

1. その事業者がGTFS・ODPTで公開していないか確認する（[GTFSデータリポジトリ](https://gtfs-data.jp/)、[ODPTカタログ](https://ckan.odpt.org/)）
2. 公式サイトで時刻表がどの形式で載っているか確認する（HTML / PDF / 画像 / 外部サイト）
3. `https://（時刻表があるサイトのドメイン）/robots.txt` を開き、時刻表ページへのアクセスが禁止されていないか確認する
4. 公式サイトの「サイトポリシー」「利用規約」「著作権について」などで、自動取得・転載・二次利用の記述を確認する。時刻表が外部サイトにある場合は、そのサイトの規約も確認する
5. 会社概要で、正式名称・本社所在地・連絡先を確認する
6. 判定と確認日を、この台帳に記録する
