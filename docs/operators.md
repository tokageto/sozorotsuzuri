# 交通事業者データ台帳

交通事業者ごとに、時刻表がどこで、どんな形で公開されているか、使うときの条件、問い合わせ先を記録する台帳です。
アプリで時刻表を扱う前に、各社のルールを守れているかを確かめるためのものです。
規約は変わることがあるため、**確認日**を記録し、使い方を変えるときに見直します（目安：半年に1回）。

> 2026-11-27 の調査は、AIがWebページを読み取って行いました。ページの文章を要約して読む方式のため、規約の引用は原文どおりでない場合があります。調査時に表示できなかったページは「調査時に読み込めず」としています。「未確認」と書いた項目や、実際に取得を始める前には、公式ページを自分の目で確認してください。

## 区分の決まり

| 区分 | 意味 | アプリでの扱い |
|---|---|---|
| 公開データ | GTFS・ODPTなどで、ライセンス付きで公開されている | ライセンスに従って使う（出典などを表示） |
| 事前に相談 | 公開データがない。サイトの時刻表を本人の記録用を超えて使うには、各社の規約に従い、了解をいただく | 了解をいただくまでは、本人が公式サイトで確認して手で記録する |
| 未確認 | まだ調べていない、または調査時にページを読み込めなかった | 本人がブラウザで公式サイトを確認するまで、何もしない |

## 確認の手順

1. その事業者がGTFS・ODPTで公開していないか確認する（[GTFSデータリポジトリ](https://gtfs-data.jp/)、[ODPTカタログ](https://ckan.odpt.org/)）
2. 公式サイトで時刻表がどの形式で載っているか確認する（HTML / PDF / 画像 / 外部サイト）
3. 公式サイトの「サイトポリシー」「利用規約」「著作権について」などで、転載・二次利用・リンクについての記述を確認する。時刻表が外部サイトにある場合は、そのサイトの規約も確認する。robots.txt も確認する
4. 読み込めないページは、本人がブラウザで開いて確認する。アクセスの制限を回避しようとはしない
5. 会社概要で、正式名称・本社所在地・連絡先を確認する
6. 区分と確認日を、この台帳に記録する
